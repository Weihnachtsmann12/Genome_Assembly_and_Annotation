# Bioinformatics: Genome and transcriptome assembly and annotation
Repository for the documented code from Matthias Rubin (08-172-090) used for courses "Genome assembly" (473637) and "Organization and annotation of Eukaryote genomes" (SBL.30004) of the University of Bern and Fribourg, taking place in Fall Semester 2024/2025.

In this readme you find an overview over the scripts that were used during the courses.

# 1. Work on the IBU cluster
The folder "scripts" contains all the scripts that were run as jobs on the cluster in the order they were run. It contains scripts for the genome assembly part and the gene annotation part.

There is also a second folder "scripts_interactive_jobs" that contains code that was run as an interactive job directly on the command line, also in the order it was run.

# 2. Work on the local machine
Fianlly, the folder "local_R_scripts" contains all the R-scripts that were used locally to generate some of the plots seen in the report, also in the order they were used.
